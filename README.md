## Overview

This repository contains lab work for **LAB 3** of the Computer Fundamentals & Career Pathways (CSE103) course at **K.R. Mangalam University**, Gurugram.

It demonstrates basic Git and GitHub operations, version control, Markdown documentation, and Python programming.

## How to Run

Clone the repository:

```bash
git clone https://github.com/itzpritam7x/cse103-lab-LAB3.git
```

Open the project folder:

```bash
cd cse103-lab-LAB3
```

Run the Python file:

```bash
python3 main.py
```

## Key Learning Outcomes

- Understanding Git and GitHub workflows.
- Creating and managing repositories.
- Tracking changes using Git commits.
- Pushing and pulling changes between local and remote repositories.
- Writing structured Markdown documentation.
- Running Python programs using the Linux terminal.
